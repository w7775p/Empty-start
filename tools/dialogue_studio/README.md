# 全游戏对话与气泡工作台

## 打开方式

1. 在 Godot 打开 res://tools/dialogue_studio/dialogue_studio.tscn。
2. 按 **F6** 运行并最大化窗口。
3. 顶部标签切换「游戏文案库」「新手教学」「开头 / 结尾漫画」。

## 已接入的数据源

- **20 主播气泡对白**：按主播、故事配置、发言方、触发类型和 ID 搜索；可编辑台词、触发键、同事件台词顺序、显示时长、定时秒数、随机权重、启用状态和备注。
- **19 直播评论**：编辑评论正文、抽取权重、启用状态和备注。
- **25 观众昵称**：编辑显示昵称、权重、启用状态和备注。评论通过稳定 viewer_id 关联昵称与粉丝身份。
- **03 神谕话语 / 04 矛盾话语**：编辑实际话语、倾向、强度、权重、富文本字段、启用状态及备注。03 表填写 `rich_text` 时，右侧预览会显示 BBCode 效果；如果富文本解析后的正文与 `text` 不一致，预览会回退纯文本并显示警告，与游戏运行时的保护规则一致。
- **24 新手教学**：复用原教学编辑器，编辑提示气泡、步骤顺序与触发/完成事件。
- **开头 / 结尾漫画**：复用原漫画文案编辑器，编辑 speech、narration、danmaku、Label、字体、字号、颜色、富文本效果、位置、尺寸、尾巴和延迟。

## 使用与保护

- 各数据源写回自己的原始 CSV 或 Resource，不会合并成新格式。编辑器只写入当前表；切换或重载前会提醒存在未保存修改。
- 复制条目会生成新 ID 并默认禁用。启用前请检查关联字段。20 表新条目必须使用程序真实支持的触发键；仅填写文本不会自动产生新事件。
- 发言方、主播、故事配置、触发类型等程序接线字段在编辑器中作为关联信息显示。触发键可以编辑，但保存前只能检查非空，无法证明代码中确实存在对应事件。
- 03 / 04 的话语会进入战斗词池；修改文本会影响游戏内容。稳定 ID、词池与主播归属建议保持不变。
- 运行中的游戏不会热更新，保存后需重新加载对应数据。当前版本编辑所有已接入来源的内容与现有参数；战斗主播气泡逐条配置字体、颜色、底板形状或动画，还需要扩展 20 表与运行时数据模型。

## 校验

- 校验稳定 ID 唯一、启用条目的正文非空、数字字段格式、显示时长大于 0 和主播对白触发键非空。
- 遇到结构异常或校验失败时阻止保存，避免把不完整内容写回正式 CSV。
