# 全游戏对话与气泡工作台

## 打开方式

1. 在 Godot 打开 \`res://tools/dialogue_studio/dialogue_studio.tscn\`。
2. 按 F6 运行并最大化窗口。
3. 通过顶部标签切换「游戏文案库」「新手教学」「开头 / 结尾漫画」。

## 游戏文案库包含

- **20 主播气泡对白**：搜索主播、故事配置、发言方和触发类型；可编辑台词、触发键、同事件台词顺序、显示时长、定时触发秒数、随机权重、启用状态和备注。
- **19 直播评论**：可编辑评论正文、关联观众 ID、抽取权重、启用状态和备注。
- **25 观众昵称**：可编辑显示昵称、权重、启用状态和备注。
- **03 神谕话语**：可编辑实际话语、倾向、强度、权重、启用状态、备注及 rich_text。
- **04 矛盾话语**：可编辑矛盾句、启用状态和备注。
- 支持搜索、复制条目（复制结果默认禁用）、保存前校验和写回各自原始 CSV。
- 每张表独立保存，不会把不同系统的数据合并成新格式。

## 新手教学与漫画

- 「新手教学」复用原 24 表编辑器：编辑提示文案、步骤顺序和教学配置。
- 「开头 / 结尾漫画」复用漫画文案编辑器：编辑 P1–P4 与 P5–P6 的 speech、narration、danmaku、纯 Label 文案、字体、字号、颜色、富文本效果、位置、尺寸、尾巴和延迟。

## 重要边界

- 主播气泡的发言方、主播、故事配置和触发类型属于程序接线，显示为关联信息。修改触发键前务必确认程序发出的稳定事件/配置键。
- 复制的条目默认禁用。启用前检查关联字段；20 表新条目需要填写有效 trigger_key / 触发条件，不能只靠新增文本自动触发。
- 03 / 04 的文本会进入游戏话语或矛盾系统；修改文本影响游戏内容。稳定 ID、词池与主播归属用于关联，建议保持不变。
- 19 评论通过 25 表的 viewer_id 找到昵称和粉丝身份。修改 viewer_id 时必须选择 25 表中存在的 ID。
- 编辑器写回项目源 CSV 或漫画 Resource。运行中的游戏不会热更新；下次加载对应数据时生效。
- 本版支持编辑文案和现有可配置参数。主播气泡逐条自定义字体、颜色、底板或动画需要额外扩展运行时数据模型；本版不会显示尚未接入的样式选项。
