## 本次任务
1. **开播入口接通**：从现有主菜单/有效存档到正式休息室；点击背景上的电脑打开三按钮菜单；点击“继续直播”调用既有 `SceneRouter.goto_game()`，进入 **`scenes/sandbox/sandbox_plan_b.tscn` 的正式 Plan B**。现有图鉴／圣典能打开与返回，不改其展示内容。
2. **战斗与教学保持真实运行**：首关已有费米气泡教程能按实际发表、✋ 改口、合法感染、费米指定 ✌️、矛盾阶段事件连续推进；其间不丢输入、不重复触发、不因快速操作截断尚未播完的话。正常战斗结束能打开本场正式结算。只修联调中可复现的断线／重复请求／空引用，不改玩法参数或新增教学。
3. **结算双选正式路由（核心）**：在 #341 的现有 `RestResultView` 按钮已经合入同一代码基线后，由唯一 Owner 连接 `Sandbox`：
   - “**继续直播**”：同一场结算只提交一次奖励与关卡进度；**直接进入下一普通关**（不先返回房间）。最后一关走既有 DivineDescent／终局入口。
   - “**暂时下播**”：提交**同一份**已结算结果和下一关进度，保存后返回 `SceneRouter.goto_opening_room()`；在休息室再次开播，从应继续的关卡进入。
   - 两按钮只在结果演出结束后启用；连点、切场景或重复信号不重复发奖、推进或创建第二个结算界面。原“PK 赢但矛盾未击破”不凭空获得击败奖励。
4. **最低限度存档回归**：下播回房间后退出／重进一次，验证已完成关卡、可用圣典／图鉴和下一关入口不丢；失败重开只检查原已有入口未被联调破坏，不修改存档格式。
5. **只接线与修断点**：优先复用现有 `RestSession`、`LevelRunState`、`SaveManager`、`SceneRouter` 与已存在信号；不重建结算页、不改系统判定，不为联调造新 Manager／Autoload／完整测试框架。

6. **底部石头剪刀布话语卡放大（用户新增明确需求）**：本卡同时修复正式 `PlanBBattleUI` 底部 `WordHand` 的可读性问题，**面板与文字一起放大，视觉效果参照两侧评论区**。当前底栏 180px、单卡最小高 98px，卡片正文 18px、按键 12px、元信息 11px；评论正文由 22 表 `comment_font_size_px=20` 控制，当前差距明显。
   - 卡片正文至少达到评论区文字的设计字号（参考 20px），标题、快捷键、强度／属性信息、石头剪刀布图标和内边距相应增大，不得继续有极小不可读字。
   - 三张卡统一尺寸，中央底栏可先尝试约 240px、高约 150px 的卡片，再用截图微调。长句自动换行且完整可读，不新增滚动容器，不用省略号掩盖字号不足。
   - **三列宽度保持 448/1024/448，左右评论区不改**。如底栏扩展需要让出中央棋盘垂直空间，协调 `UnitFieldHost` / `UnitField` 的可见高度与鼠标坐标，保证棋子不被盖住、点击命中位置无偏移。保留三卡选择、1–3 热键、冷却填充、教程高亮、类型／倾向和矛盾阶段底栏切换；不改玩法参数。
