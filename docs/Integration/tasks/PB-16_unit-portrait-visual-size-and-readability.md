## 已经实现的功能
当前棋子实际显示极小，甚至小于周边文字，玩家无法识别头像。用户此前描述原画为256×256；**当前新上传美术在PR #271中实际为六张512×512 PNG**，这一事实以素材清单为准，不应把原始纹理像素数误认为游戏显示尺寸。Plan B绘图层以视觉半径计算显示大小，物理碰撞半径另有独立配置。

## 本次任务
### 1. 先解决“棋子看不见”
1. 将PR #271最新上传的 **512×512 原画头像**的游戏内**目标显示尺寸先调整为约128×128逻辑像素**（直径128），采用清晰的纹理缩放和保持比例方式展示；所有中立、玩家和对手头像遵循同一可读规格。
2. 使用实际1024×828中央战斗棋盘，显示目标优先服从“肉眼能认出角色头像”，并允许基于**真实画面**适当修正至更适合的尺寸。请对比改前与改后的真实游戏截图，确认棋子不再比文字小。
3. 先确认 #271 中六张棋子图已按可运行分支实际接线；未合并时按现有资源做可用预览、合流时再切换最终路径。保留头像完整可见区域与当前阵营/属性标识；同步调整视觉光圈、受击反馈、尾巴指向和选择态描边的相对大小，保证外缘没有裁切。
### 2. 显示层与碰撞层分别核验
1. **本卡第一阶段只改显示尺寸**，沿用当前已运作的模拟碰撞/感染事实，观察30人起始与多人团体中的重叠、接触命中、落点及阻挡程度。
2. 根据真实截图和点选结果修正 **点击命中半径**、气泡成员锚点和贴图视觉偏移。物理碰撞半径根据实机表现另行判断必要微调范围，始终保持棋子能互相感染与结群，而不是直接把物理半径设为64px。
3. 与 PB-18 倾向色光圈共用现有绘制层；注意 PB-14 的96人口候选存在性能问题，单次画面验证同步记录明显新增的图元开销。

## 本卡验收标准（真实 Godot）
- 正式战斗里棋子头像明显大于当前版本且能分辨面部细节；给出约128px初值以及最终采用值。
- 开局30名中立的真实 Godot 截图中，人物完整显示；在较高人口时观察遮挡与可选中性，优先保证识别。
- 棋子位置仍与真实碰撞/感染相符，鼠标落点与选择态正确，帧率变化有简短记录。
