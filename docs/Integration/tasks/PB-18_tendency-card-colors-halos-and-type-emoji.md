## 已经实现的功能
玩家已有三张独立5秒刷新的话语卡，每句有当前强度和战斗克制属性。正式三倾向稳定ID为 `orthodox`、`heretical`、`absurd`；目前`data/plan_b/word_pool.csv`尚存在**`neutral`中立倾向的话语**和源表`heresy`，运行内容读取器已把`heresy`正规化为`heretical`。棋子公开快照中已有`tendency`字段，直接消费即可。玩家目前缺少易辨的卡片倾向色和场上对应棋子的同色光圈；卡片上战斗克制类型缺显式图标。

## 本次任务
### 1. 倾向负责主色
1. 根据话语运行时的**倾向 `tendency` / `tendency_id`** 映射三种稳定颜色：正统 `orthodox`、异端 `heretical`、荒谬 `absurd`。先参考项目现有倾向视觉颜色；颜色值统一放入卡牌与棋子可共享的最小配置/工具入口，以现有设计语言为准。
2. 对词池真实存在的**`neutral`中立倾向话语**，首包用统一可调**中性灰 `#94A3B8`**作为卡面/棋子光圈的低强调颜色；这仍属于有阵营归属的玩家或敌方信徒，不等同于未被感染的中立棋子。未知/空倾向遵循同一安全回退并记录数据问题。源数据`heresy`先经现有内容目录规范化为`heretical`后再着色。
3. 三张候选卡的卡面主配色（如底色/边框）按自身对应倾向显示，卡片进入使用、不可用、5秒整卡填充与补牌后仍能识别倾向。
4. 棋子读取**当前实际复读话语的倾向**并在头像旁/外沿显示同色**明显可辨的光圈**；出生、感染、敌方转换、同阵营改口时同步更新颜色。中立棋子保持原中立视觉；原阵营辨识信号继续保留。
5. 三倾向色与原玩家/敌方阵营色作为**不同信息维度**明确区分，使用固定外圈/内圈或等价层级，保证不会误把倾向理解成阵营或克制类别。
### 2. 战斗克制类型使用 Emoji 占位
1. 在每张话语卡固定位置显示独立的**战斗克制类型图标**。首包按当前 `data/plan_b/battle_type_matchups.csv` 定义：**type_a = ✊ 石头、type_b = ✌️ 剪刀、type_c = ✋ 布**，克制关系为**A克B、B克C、C克A**。采用固定位置/固定映射，并允许之后用正式icon资源替换Emoji。
2. 当场上克制类型需要说明时，在卡面或现有帮助区域用一行简单图例说明 ✊＞✌️＞✋＞✊，不另增整套教学系统。Emoji 与倾向配色、强度数字各自表达不同信息：图标用于克制，颜色用于三倾向，强度仍保留2/4/8数量对应的原规则。
3. 采用能够稳定渲染的字体/字形回退；如 Godot 当前字体缺失彩色Emoji，可采用同义可见符号或现有字形作为这张卡的临时图标，并记录实际显示情况。
### 3. 视觉验收
1. 使用真实三卡、两阵营和改口后单位进行截图；检验各色卡与光圈匹配及三种 Emoji 的清晰度与映射准确度。
2. 控制光圈的绘制开销，与PB-16的棋子大图及PB-14的性能诊断协同观察。

## 本卡验收标准（真实 Godot）
- 三倾向各有稳定区分的卡面颜色；中立倾向话语使用灰色回退，源表heresy规范化为heretical；同词棋子旁能找到完全对应的倾向色光圈。
- 棋子换话/换阵营会相应更新光圈的倾向色，阵营辨识依旧清楚。
- 每张卡均有与真实战斗克制类型对应的 Emoji/清晰占位图标，随机补牌后信息正确。
- 实际 Godot 录屏展示连续三卡操作、5秒刷新、卡面配色和场上光圈。
