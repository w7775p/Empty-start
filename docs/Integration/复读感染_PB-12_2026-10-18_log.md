## 公开接口与交接

```gdscript
configure_level(level: LevelProfile) -> bool
draw_player_speech_word(
    used_word_ids: Array[String],
    occupied_word_ids: Array[String],
    level_context: Variant = null
) -> Dictionary
get_available_word_ids(team: String, used_word_ids: Array[String], level_context: Variant) -> Array[String]
set_random_seed(seed_value: int) -> void
```

- 开局抽三槽时逐次抽取，将已抽到的卡位 ID 追加到 `occupied_word_ids` 后再抽下一槽。
- 槽位刷新时只传另外两槽占用的 ID 与 A 的已用 ID。当前槽旧词已经在 A 的 used 列表时会继续被排除。
- D 负责三张固定卡位的展示和进度填充；A 在成功发表时启动对应槽的五秒倒计时，失败时不启动。C 只返回下一条可用词定义。
