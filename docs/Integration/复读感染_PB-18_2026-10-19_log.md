## 核对结论

C 已有可供 D/A 使用的稳定词条字段和克制查询；PB-18 沿用这些字段，并在同一 `data/plan_b/` 配置层补充一张按类型归一的显示图标表：

- `systems/plan_b/content/plan_b_content_catalog.gd` 的 `get_word_definition(word_id)` 返回 `battle_type`、规范化 `tendency_id` / `tendency` 和原始 `source_tendency`。
- 同文件 `get_type_matchup(attacker_type, defender_type)` 返回 `advantage`、`disadvantage`、`same`。
- `data/plan_b/word_pool.csv` 的 `battle_type`、`tendency` 保留词条来源；`data/plan_b/battle_type_matchups.csv` 定义完整三角关系：`type_a > type_b > type_c > type_a`。
- `data/plan_b/battle_type_emoji.csv` 将当前类型 ID 映射为稳定显示占位；`PlanBContentCatalog.get_battle_type_emoji()` 与词条快照字段 `battle_type_emoji` 提供同一读取值。
- `docs/17. ThreeTendencies/README.md` 与 `TendencyState` 使用稳定 ID `orthodox / heretical / absurd`；03 源表 `heresy` 在 C 快照中映射到 `tendency_id=heretical`，并保留 `source_tendency` 便于审计。

## Emoji 映射交接

用户确认首包显示占位：`type_a=✊`、`type_b=✌️`、`type_c=✋`。现有关系表校验 A克B、B克C、C克A，映射只表达该循环，克制算法仍由 `battle_type_matchups.csv` 控制。映射状态标为 `pb18_user_approved_placeholder`；V0.4 对类型正式名称/顺序的待定说明仍生效，类型 ID 变更时需同步更新该表。

D 可使用词条的 `battle_type_emoji` 显示卡面图标、用 `battle_type` / `get_type_matchup()` 消费克制信息，并用 `tendency_id` 选择倾向色；图标、倾向和强度各自表达不同信息。PB-16 最新规格为棋子显示128×128、圆形物理半径64px，视觉与碰撞接线仍归 D/B/A。

本卡只修改 C 数据读取与配置，没有修改 UI；Emoji 仍是可由正式资产替换的显示占位，最终渲染由 D 接线验收。
