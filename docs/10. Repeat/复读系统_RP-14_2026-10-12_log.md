## 2. 真实入口与当前能力

- `BattleAttemptFlow._on_shot_hit_resolution_submitted()` 从本发结算的 `target_results` 读取 `original_sentence_id` / `original_sentence_text`，创建普通 `RepeatPlan`、应用既有纯文本模板并加入 `RepeatDelayQueue`。
- `ContradictionOracleFlow._on_contradiction_shot_created()` 从本发冻结的矛盾事实创建矛盾复读计划，沿用相同的原句身份与队列。
- `DivineDescentSpread.generate_next_repeat()` 从进入时冻结的历史候选读取原句 ID / 文本后创建复读计划。
- `BarrageArea.spawn_repeat_barrage()` 将已有 `display_text` 写入 `BarrageRuntimeRecord.text`，并独立保留 `original_sentence_id` / `original_sentence_text`。
- `BarrageView` 的前景 BBCode 仅作用于 `RichBody` 覆盖层；`get_visual_plain_text()` 从运行记录取得原文。复读拒绝 `set_visual_bbcode()`，直接显示自身记录文本。
- `RepeatDelayQueue` 在成功创建视图后按该计划类型记录 1 条实际生成；未生成的延迟请求不计入统计。
