# RP-18 同一原句的静止复读接续涌现

**状态：已有原句及延迟队列 · 待静止生成表现联调**

- docs/Original/任务卡模板.md、known_traps.md
- `AGENTS.md`、`project.godot`、本系统 README 与最新完成日志

## 已经实现的功能
`RepeatPlan` 保存原句 ID、显示文本、结算 Tier 与生成数量；延迟队列已经能在不同时间发出同一句的多个复读请求。

## 本次任务
同一次有效命中产生的同句复读按原有延迟接续显示，形成**多点静止复读群**。

### 触发条件
一句普通话语有效命中并产生多条普通复读计划时。

### 预期行为
继续使用既有随机延迟队列与来源 ID，使多条同句复读陆续出现在中央战斗区各个随机位置；每一条落点确定后保持静止，按各自寿命淡出。以重复出现的数量与时间顺序表现舆论涌现。

### 验收条件
同一句话被击中后，相关复读随时间在中央区域不同位置陆续出现并保持静止；实例原句关联、实际生成数量及消失释放容量正确。

## 本卡专项交付说明
提交联调与 Godot 实际运行验收，更新 README 和日期日志。
