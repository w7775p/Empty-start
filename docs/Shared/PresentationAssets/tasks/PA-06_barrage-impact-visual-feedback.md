## 本次任务

根据现有攻击到达与特性结果，为弹幕显示以下**短促、辨识度高的命中动画**，使用 Godot 动画、形变、2D 曲线裁切 / 遮罩及程序生成图形完成。

### 1. 普通弹幕：曲线式瞬间击碎
- 参考《女神异闻录 3 Reload》《女神异闻录 5 Royal》的风格化图形切割感。
- 命中瞬间以**曲线或弧线裂开底板**，在极短时间内完成分割与消隐，呈现爽快、有冲击力的**瞬间碎裂**效果。
- 使用少量整体分割形状、遮罩或短帧动画，形成清晰有力的瞬时碎裂。
- 在命中目标**旁边**同步弹出**漫画式强调符号**，参考「∑」这类夸张符号的视觉语言，突出碎裂瞬间的冲击感。
- 漫画符号优先使用 Godot 程序绘制或 SVG 生成透明 PNG，并提供替换为美术绘制资源的入口。
- 漫画符号的尺寸、偏移、颜色及动画时长集中可调整。

### 2. 遮挡弹幕：铁质硬碰
- 当攻击区域接触遮挡话语、整发依据 CA-15 判为落空时，在铁质底板上播放短促的**硬质撞击反馈**，例如局部高光闪击与受力震动。
- 撞击之后遮挡与本发范围内的其他话语都保持原状，以材质的坚硬感表达整发落空。

### 3. 分裂弹幕：母体分开，子体转为普通玻璃
- 命中时沿已有预裂曲线做一次快速**裂开 / 分离**视觉。
- 使用程序系统实际生成的子弹幕数量和对应文本、倾向及强度，将新子弹幕表现为 PA-04 的普通玻璃外观。
- 分裂母体的表现与现有一次性分裂触发、子弹幕生成流程衔接。

### 4. 反弹弹幕：果冻回弹
- 命中时通过**受压变形 → 伸展回弹 → 恢复**的短动画表现柔软弹性。
- 高光和轮廓随果冻形变同步变化，形成明显的弹性反馈。
- 衔接 PA-05 中反弹弹幕的常态 Q 弹表现与现有反弹结果。

### 5. 假复读与水军反击的命中反馈
- **假复读**：沿用普通玻璃的短促曲线碎裂方式，碎裂轮廓匹配 PA-05 的椭圆气泡；命中时保留其更鲜艳的原配色直至消隐。
- **水军反击**：将 PA-05 的整块不规则 Panel 作为**一个弹幕实例**播放整体的破碎 / 收缩消隐，内部重复的小字随同一个 Panel 一起退场。
- 特殊结果的文字提示、主播侧受击与 PK 数值反馈由 PA-09 接入本次效果。

### 6. 动画接入
- 读取现有攻击到达与特性结果，按照普通、遮挡、分裂、反弹类型调用对应视觉反馈。
- 弹幕实体被真实生成 / 命中系统移除时，使用独立短生命周期的特效层 / 临时显示副本承接碎裂图形，让实际弹幕正常结算和退场，**视觉碎裂仍可完整播放到结束**；暂停与新一场开始时按现有生命周期收束残留特效。
- 动画参数以可调整形式集中管理，以各 Tier 少量可读前景和较多底层复读的实际组合验收表现开销。

### 验收条件
- 正常命中的玻璃弹幕以曲线切割感迅速碎裂消失，旁边出现与动作同步的漫画式强调符号（如「∑」）。
- 铁质遮挡命中时出现硬质反馈，底板保持完整。
- 分裂母体沿裂痕分开，实际生成的子弹幕使用普通玻璃材质。
- 果冻弹幕命中后呈现明确的受压、回弹与恢复动作。
- 假复读椭圆气泡与水军反击整块 Panel 均具备各自完整的命中消失效果，水军 Panel 保持一次命中对应一次退场。
- 现有战斗结果与弹幕交互继续正常，视觉运行画面及 Godot Output / Debugger 验证通过。
