## 本次任务

采用**分级混合**视觉语言：普通命中使用克制的文字反馈；特殊异常与玩家受到惩罚时使用夸张手绘漫画提示。提示位置采用已确认的 **C 方案**：**命中点附近显示局部反馈；玩家受到惩罚时，在我方主播立绘旁弹出夸张漫画提示。**

### 1. 命中点局部反馈
- 正常话语命中时，在命中弹幕附近显示小字号、短距离移动并消隐的轻量反馈，与 PA-06 的材质破碎动效配合。
- 遮挡、反弹、假复读、水军反击等特殊结果，在相应命中点附近显示短促、易识别的局部结果提示。
- 落空时在准星 / 发射目标附近显示简洁的落空提示。
- 结果文案可配置；`MISS`、`BLOCK`、`REFLECT` 仅作为展示示例。
- 高密度弹幕和同发多目标时，保持提示短促、小面积、易读；按目标实际位置显示，与 PA-06 原有漫画符号形成统一视觉节奏。

### 2. 我方主播旁的受惩罚漫画提示
- 当**本发攻击最终汇总的 PK 净变化小于 0** 时，在**左侧我方主播立绘旁**弹出一次独立的夸张漫画受击提示。读取 `shot_hit_resolution_submitted` 中现有结算结果的 `total_pk_delta`；该值为正或等于 0 时，主播保持普通状态。
- 提示采用策划现有受击效果参考的**手绘漫画风**：粗细起伏、非规则笔触、深棕近黑主色、浅橙辅助弧线与尖锐强调碎形。
- 动效以**突然弹出 → 短促抖动 / 扩张 → 快速收回或淡出**表达受击冲击，文案或图形可替换。
- 假复读、反击、反弹、遮挡、落空的每项目标反馈仍按其结果显示；**主播受击统一看本发汇总后的 PK 净变化**，同时命中正负目标时也按汇总结果决定。
- 多目标同发时，主播侧最多播放**一次**受击漫画反馈，和本发净 PK 变化对应；持续的对手 PK 回拉由原有 PK 条表现，不用每帧触发主播受击动画。

### 3. PK 数值的轻量提示
- 在顶部 PK 条附近，以小字号、短促浮字或条形回弹辅助表达本发结算的 PK 变化。
- 正向和负向变化使用清晰的亮度 / 颜色对比，大小与动画强度整体弱于主播侧受击提示。
- 多条目标同发时，从现有最终结算数据读取整发变化，文字显示与 PK 条动作保持同步。

### 4. 统一表现与接入
- 使用 Godot 原生 Label / RichTextLabel、Control、Tween、AnimationPlayer、`_draw()` 或可替换的 SVG/PNG 图形资源实现。
- 优先复用已有结果事件、HUD 与 PA-06 的命中反馈节点 / 表现入口，使位置、缩放、暂停及场景清理与现有战斗协同。
- 集中提供字体 / 字号、颜色、描边、位移、缩放、透明度、动画时长与主播侧偏移等美术参数。
- PC / Android 的对应画面中，局部文字、主播立绘漫画提示和 PK 数值提示均保持可辨识。

### 验收条件
- 普通命中于对应弹幕附近显示克制的局部反馈，PA-06 的碎裂 / 命中图形正常播放。
- 假复读、水军反击、遮挡、反弹、落空等异常出现对应局部结果提示；**仅在本发最终 PK 净增量为负数时**，我方主播立绘旁出现一次夸张的手绘漫画受击提示。
- 玩家侧漫画提示能体现策划已提供的手绘笔触语言，明显区别于普通命中的小字号反馈。
- PK 条附近显示与本发结果一致的简洁数值反馈；一发多目标时提示仍保持清晰。
- Godot 实际运行画面及 Output / Debugger 验证通过，适配 Windows / Android。
