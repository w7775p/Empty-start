## 本次任务

采用**低噪声数值反馈**：普通命中由 PA-06 材质响应与准星旁的本发数值表达；异常仅在目标附近出现必需的结果词。顶部 PK 条与主播画面保持原样，常规受击不额外弹出漫画符号。

### 1. 命中点局部反馈
- 正常话语命中仅播放 PA-06 的材质碎裂与准星旁本发数值反馈；取消普通 `HIT` 结果词。
- 遮挡、反弹、假复读、水军反击等特殊结果，在相应命中点附近显示短促、易识别的局部结果提示。
- 落空时在准星 / 发射目标附近显示简洁的落空提示。
- 结果文案可配置；`MISS`、`BLOCK`、`REFLECT` 仅作为展示示例。
- 高密度弹幕和同发多目标时，异常结果词按各目标实际位置短促呈现；正常目标只使用材质响应，避免重复文本。

### 2. 常规主播受击表现简化（2026-10-11 变更）
- 本发总 PK 净值为负时，由准星旁负数与更强字号、阴影提示亏损；**我方主播旁不再额外播放独立受击漫画**。
- 不因同发多目标增加额外漫画；仓鼠区域的角色动画与本卡 UI 局部反馈解耦。
- 漫画表现留给独立的击破 / Paradox 等高价值演出任务。

### 3. 准星旁本发净值浮字（2026-10-11 策划修订）
- 本发 PK 净变化的数值浮字仅在准星旁显示，与本发攻击位置对应；PK 条不显示浮字。
- 使用最终结算的整发净值，按绝对值映射表现强度：数字越大，**字号越大，阴影越重**。正负数用可读的颜色区分。
- 多目标同发时，准星旁只显示一个汇总净值；仅特殊异常目标在命中点显示对应结果词，正常 HIT 不另行显示。
- 只新增局部战斗反馈；沿用现有 Sandbox HUD、PK 条、主播区与布局，不重新设计或添加 HUD 皮肤。

### 4. 统一表现与接入
- 使用 Godot 原生 Label / RichTextLabel、Control、Tween、AnimationPlayer、`_draw()` 或可替换的 SVG/PNG 图形资源实现。
- 优先复用已有结果事件、HUD 与 PA-06 的命中反馈节点 / 表现入口，使位置、缩放、暂停及场景清理与现有战斗协同。
- 集中提供字体 / 字号、颜色、描边、位移、缩放、透明度、动画时长与主播侧偏移等美术参数。
- PC / Android 的对应画面中，必要异常结果词与准星旁净值浮字均保持可辨识。

### 验收条件
- 普通命中只触发 PA-06 玻璃碎裂等材质响应，不出现额外的漫画贴图或 `HIT` 字。
- 遮挡、反弹、落空等必要异常出现相应局部词；我方主播立绘旁不再出现常规受击漫画。
- 无论结果正负，准星旁统一承担整发净值反馈；同发多目标只显示一份汇总数值。
- 准星旁显示与本发结果一致的单份数值浮字，数值绝对值越大字号与阴影越大；顶部 PK 条保持原样，一发多目标时提示仍保持清晰。
- Godot 实际运行画面及 Output / Debugger 验证通过，适配 Windows / Android。

### 3. 保持最小必要复杂度
- 依赖方向清晰、代码高内聚；拆分场景或脚本以独立变化、生命周期、状态、流程或复用等实际需求为依据。

### 4. 组合优于继承

### 5. 保持场景边界
- 父场景协调生命周期与组合，子模块维护自身状态；跨系统通过公开接口、稳定 ID、signal 或数据对象协作。

### 6. 区分场景、逻辑和数据
