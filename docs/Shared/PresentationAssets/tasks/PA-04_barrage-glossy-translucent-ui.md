## 本次任务

### 1. 玻璃底板
- 为每条普通弹幕制作随文字内容适配尺寸的**圆角半透明底板**。
- 参考《如龙0》电话交友俱乐部消息板，呈现**明亮、光滑、轻微厚度感的塑料玻璃材质**。
- 通过边缘高光、轻渐变与细腻的轮廓表现材质。
- 优先采用 Godot `StyleBoxFlat`、`Theme`、`_draw()` 或轻量 Shader；需要图形资源时可由 SVG 生成 PNG。
- 集中配置底板颜色、透明度、圆角、轮廓和高光参数，方便统一换色。

### 2. 倾向与强度的底板外观
- 为**正统、异端、荒谬、Neutral** 提供可配置的**整块底板配色**，用色系辨认倾向。
- 让强度 **1 / 2 / 3** 对应同一材质家族的逐级强化外观：通过底板亮度、边框存在感、内部渐变、高光及透明度的组合增强视觉权重。
- 强度 1 使用基础玻璃效果，强度 2 更醒目，强度 3 具有最强的视觉吸引力，传达“快来打我”的目标感。
- 倾向与强度组合显示时，保留倾向色系和强度层级。具体色值及材质数值提供可调参数。

### 3. 富文本文字与基础字效
- 复用 BG-28 的单句局部富文本呈现接口，在普通前景话语中显示 BBCode 多段样式；基础文本描边接 BG-37。
- 在已有字体资源上实现 **B1 清晰单层描边 + B3 轻微浮雕感**：高对比实心文字、清晰描边、细微偏移阴影。
- 使文字填充、描边与阴影参数可以集中调整，保证与半透明玻璃底板协调。
- 让文本布局和底板尺寸适配不同长度的消息。

### 4. 既有元素与运行接线
- 普通前景使用倾向/强度底板；普通复读采用圆角气泡、灰色纯文本、零文字描边、固定底层与逐渐透明的展示规则（RP-14、RP-16～RP-21）。**粉丝牌沿用当前已接线的显示规则**，不因这次玻璃底板制作改变；弹幕本体独立于粉丝牌完成美术验收。等 PA-10 整屏视觉统一时，再根据实际画面决定普通弹幕 / 复读的粉丝牌是否调整。
- 继续提供现有弹幕运行接口，保持特性表现、战斗交互、缩放反馈、移动及生命周期正常运作。
- 使用现有弹幕运行记录获取倾向、强度与文本，为底板样式绑定对应参数。
- 让同一套外观能够在大量弹幕同屏时保持清楚的视觉层次。

## 验收
- Godot 实际运行中，普通弹幕显示半透明亮面圆角塑料玻璃底板。
- 四种倾向呈现四套可配置的底板配色；同一倾向下三档强度的视觉醒目程度依次增加。
- 普通及挂特性的前景话语具备清晰单层描边与轻浮雕；普通复读呈灰色纯文本、零文字描边，并持续位于前景话语底层。
- 普通圆角复读气泡正常显示；当前已接线的粉丝牌如仍启用则继续显示，弹幕原有交互、移动、寿命及表现接口继续可用。
- 通过多条弹幕重叠的画面检查可读性；Godot Output / Debugger 检查通过。
