## 当前需求与视觉定位
- Paradox 是 **T5 PK 满值后进入的独立 T6 矛盾击破阶段**。正式阶段按最新 CB 需求呈现 **1 真 + 5 假，共六句矛盾话语**，10 秒倒计时、一次正式发射机会；六句话先运动再逐渐减速至停止，运动期间已经可以攻击。
- 视觉参考：《逆转裁判》的反驳漫画冲击与《弹丸论破》的辩论文字切割。整体使用**漫画分镜、斜向切割、瞬间闪白、撞击字体、画面撕开**构成演出。
- 已确认原型中的三条静态候选与按钮点击是演示占位。正式阶段展示现有六句矛盾弹幕及环形准星；视觉图形、节奏和幕布按本卡分镜执行。

## 本次任务

### 1. 从普通战斗进入矛盾阶段的分镜转场
按策划确认的原型，制作一套完整可播放的过渡，画面依次呈现：

1. **噤声 / 压暗**：普通弹幕被现有阶段流程清理后，中央战斗画面快速变暗、降低饱和度，形成短促的空场停顿。
2. **两道漫画斜切**：绘制两条**粗、斜向、边缘不规则的漫画切割带**，分别从相对方向高速掠过，在中央交叉；切割带使用浅色主体、红色切边、深色轮廓及少量拖影。
3. **撞击闪白**：斜线交叉瞬间，画面出现短促亮白闪烁、放射状尖锐冲击线与轻微画面震动。
4. **大型漫画标题**：中央弹出 **「矛盾击破！」** 大字，采用斜体 / 倾斜构图、粗描边、硬质偏移投影和短促的**过冲缩放 → 回弹定位**；提供可替换的文案及字体资源入口。
5. **斜向画面揭开**：浅色与红色两块**不规则斜切遮罩 / 漫画分镜幕布**从中间向左右拉开，露出矛盾阶段的真实战斗界面；标题同步上移缩小并淡出。
6. **切换完成**：遮罩、冲击线和闪白清理干净，留给现有 Paradox 话语、准星、倒计时与发射反馈正常显示。

- 动画时间点参考已确定的演示节奏：大致在开始后 **0.7 s 噤声、1.3 s 斜切、1.9 s 标题冲击、2.6 s 揭开、3.6 s 展示完毕**；各段时长集中可调整。转场层揭开并结束后，向现有阶段协调方发出可开始正式 Paradox 展示的完成通知。
- 让转场层与现有中央 1024 宽战斗区、左右主播立绘形成完整构图，明亮冲击帧短促，转场结束后各 UI 恢复正常可读性。

### 2. 矛盾战场视觉氛围
- 参考原型的**深色背景、偏奶油白与红色对比、斜向色块、放射线、硬边阴影**，为 Paradox 提供可调整的独立视觉状态。
- 在战斗区顶部显示清楚的**矛盾击破阶段名、剩余时间**，并为一次攻击机会提供醒目但不抢夺准星注意力的状态表现。
- 对 CB-13 已生成的一真五假六句使用该阶段视觉样式，**运动、减速和射击仍由 CB-13 / CB-14 的既有接口提供**；每句显示真实文本和实际可命中区域。
- 倒计时临近结束时，通过**颜色变化和轻微放大 / 跳动**提示紧迫感；文字大小、颜色、位置、震动幅度均可调整。
- 左右主播区保持与中央矛盾画面协调的对峙氛围，可用轻量压暗、局部轮廓强调或配色变化表现。

### 3. 命中后的漫画结果反馈
- 读取现有矛盾结算结果，在判定出现时显示短促大字冲击：例如**「击破！」/「未击破」**，使用与本次斜切转场一致的斜体、粗描边、色块偏移阴影、弹出回弹与冲击线。
- 文案与结果一一对应，反馈结束后交还已有终结神谕 / 休息流程的画面切换。

### 4. 程序美术实现与参数
- 优先使用 Godot 原生 `Control` / `Node2D`、`_draw()`、`AnimationPlayer`、Tween、`CanvasItem` Shader、遮罩与现有 UI 组件实现斜切、画面撕开和文字动效。
- 分离可调整的纯视觉参数：分镜时长、切割角度 / 宽度 / 速度、闪白亮度、冲击线数量、标题大小 / 描边 / 偏移阴影、幕布颜色 / 打开距离、背景暗化程度、倒计时警示表现。
- 使用现有阶段进入、矛盾候选显示、限时与结算结果入口连接视觉动画，向场景协调方提供**转场播放完成**的表现通知。正式 **10 秒窗口在转场幕布完全揭开、六句可见且可以瞄准时开始**；六句话一出现即可射击并按现有曲线减速。与 CB-04 / CB-13 / CB-14 的计时和运行接线由既有阶段协调方衔接；本卡实现画面与完成通知。保持 Windows / Android 下布局与动画比例正确。

### 验收条件
- 实际运行中，T5 满 PK 进入 Paradox 后能完整播放**噤声 → 双斜切 → 交叉闪白 → 漫画大字 → 左右撕开 → 矛盾战场**的演出。
- 画面构图与本卡已明确的分镜、色彩和节奏一致，具体效果由 Godot 程序美术呈现；大型标题与结果字具有清楚的粗描边、硬阴影与回弹动作。
- 转场结束交出完成通知后，由 CB-13 / CB-14 展示当前 **1 真 + 5 假六句话语**并支持移动期间射击；已接入的正式 10 秒窗口与一次机会 UI 清楚可见，10 秒从目标可见、可操作的节点开始计。
- 真矛盾击破、未击破或超时后能显示相应短促漫画结果反馈，衔接现有后续流程。
- 各美术参数可调；1920×1080 基准及 Windows / Android 适配画面可读；实际 Godot 运行与 Output / Debugger 验证通过。
