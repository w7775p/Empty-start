# 表现资产｜PA-08｜2026-10-11｜正式 Sandbox 准星动画接线补齐

## 结果
用户反馈独立 PA-08 准星预览正常、但 main 实际战斗里没有预览的蓄力与发射动效。核查确认：原 PR #111 已将 `AimReticle` 的程序绘制与表现接口合并，但 `SandboxBattleHud.refresh_attack()` 仅更新原 `ChargeProgress`，未把 `AttackChargeInput` 真实蓄力状态传给 `AimReticle.set_charge_visual_state()`；`shot_snapshot_created` 也仅驱动仓鼠立绘射击，未触发 `AimReticle.play_shot_feedback()`。因此实战缺少充能圆弧、满蓄强调与发射短闪。

## 修改
仅调整 `scenes/sandbox/sandbox_battle_hud.gd`：
- `refresh_attack(progress, phase)`：保留既有 HUD 进度条，用同一真实 `progress`，并从已绑定的 `AttackChargeInput` 调用 `is_charge_held()`、`is_fully_charged()` 后同步给 `AimReticle.set_charge_visual_state()`。
- `play_player_shot(snapshot)`：只有有效的正式发射快照才调用 `AimReticle.play_shot_feedback()`，同时保持原角色立绘射击演出；即使当前立绘隐藏也不会吞掉准星短闪。
- `reset_for_attempt()`：通过 `AimReticle.reset_visual_state()` 清理上一场遗留的视觉进度和短闪。
- 正式 `AimReticle`、CombatAttack 判定、1920 设计下视觉 96px 与实际命中圆 144px、游戏 HUD 布局、美术配色均未改动。
