## 公开调用接口

- `set_charge_visual_state(progress: float, is_held: bool, is_fully_charged: bool)`：宿主每帧输入唯一真实蓄力事实；内部平滑仅改变显示值。
- `play_shot_feedback()`：在 **`AttackChargeInput.shot_snapshot_created`** 事实产生时播放短时发射高亮。
- `animation_finished`：短时发射演出结束时发送一次；重新触发会从头播放。
- `reset_visual_state()`：恢复空进度和待机状态，停止当前发射演出。
- `set_visual_paused(paused: bool)`：暂停/继续表现时间，保留当前动画进度。
- `get_display_charge_progress()`、`is_shot_feedback_playing()`：用于断言或可选调试。
- 原有 `restore_mouse_aim()`、`move_touch_aim()`、`refresh_mouse_position()`、`get_aim_center_global_position()`、`intersects_target_area()` 完整保留。命中区域继续根据 `reticle_diameter` 计算；环形美术层始终围绕同一中心绘制。

外部接线示例（由 Sandbox 重构完成后实施）：

```gdscript
# 普通蓄力帧中仅传递攻击系统状态。
reticle.set_charge_visual_state(
    attack.get_charge_progress(),
    attack.is_charge_held(),
    attack.is_fully_charged()
)

# 发射快照已固定才开始视觉反馈。
attack.shot_snapshot_created.connect(func(_snapshot): reticle.play_shot_feedback())
```

## 可调美术参数

`aim_reticle.gd` 的 Inspector 导出分组：**判定与位置**（`reticle_diameter`，PC 默认命中直径 **144**）、**空心圆与环形蓄力**（`visual_diameter`，PC 视觉范围 **96**；空心圆半径、轨道间距 / 线宽、深色对比描边、五种状态颜色）及 **短时动态**（蓄力平滑、移动、发射、满蓄脉动）。96×96 约束的是绘制画面最外缘，视觉尺寸与圆形命中直径彼此独立；移动端命中直径继续由既有 `MobileAttackInputConfig` 注入。

1. 脚本解析：Godot `--check-only --script` 分别检查 `aim_reticle.gd` 和 `pa08_reticle_demo.gd`，退出码均 **0**。

3. 真实图形运行：Godot 4.7.2 使用 OpenGL Compatibility 启动 `scenes/demos/pa08_capture_1920.tscn`，GPU SubViewport 产出 **四张 1920×1080 PNG**；四阶段截图全部保存成功，发射后完成信号计数为 **1**，程序退出码 **0**；本次独立图形运行的 stderr 无新增脚本报错。
4. 按 PC 定稿数值重新检查了四状态画面：视觉圈限定在 96×96 范围内，深色外描边与浅色内环在暗背景上分层清楚；青色蓄力、金色满蓄、发射短闪可辨。查看 `previews/pa08_approved_96x144_detail.jpg` 的真实 GPU 截图；原四状态 PNG 与 `pa08_contact_sheet.jpg` 已刷新。**尚未在真实多弹幕混战背景中完成可见性与 Android 真机手感验收**。
