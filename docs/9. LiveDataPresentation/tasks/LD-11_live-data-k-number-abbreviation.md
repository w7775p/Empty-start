## 已经实现的功能
- `LiveDataHud` 已使用四个独立 `RichTextLabel` 显示观看、点赞、评论、粉丝。
- `set_values(viewer_count, like_count, comment_count, fan_count)` 接收整数；`_render_metric()` 负责文字显示。
- 玩家区采用 ICON → 数字，敌方区采用数字 → ICON；数值刷新支持真实 `LiveSessionData.changed` 与显式 `set_values()`。
- 当前未绑定数据源时，`_refresh_values()` 会读取标签的已显示文本重新排列图标与文字；缩写后的显示需要继续保留调用方提供的实际整数。

## 本次任务
**直播数据的整数显示从 1000 起转换为带一位小数的 `k` 缩写。**

### 触发条件
直播数据任意一项数值刷新，或 HUD 的图标、左右展示方向发生变化时。

### 预期行为
1. 观看、点赞、评论、粉丝四项共用一致的数值显示格式。
2. 数值 0～999 直接显示原整数；数值从 1000 起，以千为单位显示一位小数，并加小写字母 `k`。
3. 数值显示示例：

   | 实际整数 | HUD 显示 |
   | ---: | :--- |
   | 0 | `0` |
   | 999 | `999` |
   | 1000 | `1.0k` |
   | 1100 | `1.1k` |
   | 12500 | `12.5k` |

4. 玩家区继续显示 `👤1.0k` 一类的 **ICON + 缩写数字**；敌方区继续显示 `1.0k👤` 一类的 **缩写数字 + ICON**。
5. 格式转换只影响 HUD 可见文字，直播数据源及调用方继续使用原始整数；未绑定真实数据源时，重新排版也继续使用本次传入的真实整数。

### 验收条件
- 四项指标分别从 999 变为 1000 时，可见显示准确从 `999` 更新为 `1.0k`。
- 1000、1100、12500 的显示符合示例；小数位与 `k` 大小写一致。
- 玩家区与对手区均能正确使用此规则；切换展示方向或修改 ICON 后，`1000` 仍正确显示为 `1.0k`。
- `LiveSessionData` 中四项数值和接收 `set_values()` 的整数保持真实值，例如展示 `1.0k` 时实际数据仍为 `1000`。
- Godot 4.7.2 实际战斗 HUD 可以正常显示与刷新，输出相应运行验证记录。
