# LD-16 战斗时启动与重置双方直播评论流

**状态：待开发 · 普通直播评论流**

## 开始前阅读
- `AGENTS.md`、`project.godot`、本系统 README 及最新完成日志
- 现有 `LiveDataHud`、`Sandbox`、源表导出器与主播粉丝牌资源
- 前置或接口参考：LD-12～LD-15；现有 Sandbox / LiveDataHud / LevelProfile

## 当前实现与复用入口
`Sandbox` 当前实例化 `%LiveDataHud` 与 `%OpponentLiveDataHud` 并通过 `bind_live_session()` / `set_values()` 更新四项数字；双侧评论尚未接入其生命周期。

## 本卡唯一功能
战斗时启动与重置双方直播评论流。

## 触发条件
Sandbox 启动当前直播、暂停恢复、当前关重开、切换到下一关或离开直播时。

## 应发生的行为
将 LD-12～LD-15 已实现的双侧滚动评论流接入现有直播 HUD：开播分别启动两侧随机评论，暂停/恢复与游戏进程同步，重开和切关时清理旧显示行与计时并按当前关 `LevelProfile.streamer_id`、本侧粉丝牌及 LD-12 的可选 `streamer_id` 筛选结果重新建立评论流；通用评论与当前对手专属评论共同参与随机抽取，直播结束时停止刷新。保持现有四项数字及原本 `LiveSessionData` 数据绑定方式。

## 验收
进入直播后双侧均自动滚动评论；ESC 暂停期间刷新与滚动暂停，恢复后继续；原地重开与切关不残留旧评论、旧对手专属候选及旧对手徽章；直播离开后不继续生成；观看、点赞、评论、粉丝四项指标仍能按既有 LD-01～LD-11 规则刷新。
